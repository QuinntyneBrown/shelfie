# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing issues before filing a new one to avoid duplicates.

- **Bugs:** open a [bug report](https://github.com/QuinntyneBrown/shelfie/issues/new?template=bug_report.md).
- **Feature requests:** open a [feature request](https://github.com/QuinntyneBrown/shelfie/issues/new?template=feature_request.md).
- **Questions:** open a [discussion](https://github.com/QuinntyneBrown/shelfie/discussions) or an issue labelled `question`.
- **Security issues:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Documentation

- [README](README.md) for an overview and getting started.
- [CONTRIBUTING](CONTRIBUTING.md) for the development and pull request process.
- [AGENTS.md](AGENTS.md) for the working agreement, build budget and engineering rules.
- `docs/` for requirements, mocks, design system, detailed designs and estimates.

## Support policy

Shelfie is a personal project maintained in spare time. Support is provided on a best-effort basis through the channels above. There is no guaranteed response time.
