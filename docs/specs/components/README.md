# Component requirements documents

One pair of files per `sh-*` component: the requirements (`.md`, ending in Given/When/Then acceptance criteria that trace to L2) and a rendering (`.html`) of every variant and state in both themes. A CRD is written before a component is built or changed; see the `writing-component-requirements-documents` skill.
