How Nia's daily reading streak counts up.

Five days in a row

How the days count

  • Read today: the streak includes today
  • Not yet today: the streak up to yesterday still stands
  • Nothing today or yesterday: back to zero

Two missed days: zero days

Things to remember

  • Top bar and shelf show the same number
  • Today counts once it is read
  • Two missed days start again from zero
