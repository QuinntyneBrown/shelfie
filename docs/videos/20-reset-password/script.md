# 20 · Reset password

## Introduction

Grown-ups forget passwords too. This video shows how Dad chooses a new one by e-mail, in about a minute.

## Resetting the password

On the sign-in page, Dad presses Forgot your password? He types dad at example dot com and presses Send reset link. Shelfie says that if that address has a Shelfie account, a reset link is on its way. It says exactly the same thing for any address, so nobody can use this page to find out who has an account.

The link arrives by e-mail and works for one hour. Here a local test mailbox stands in for Dad's inbox. The link opens Choose a new password, with his address shown underneath. He types the new password twice and presses Save new password.

Password updated. He is signed in on this device, and any other device will ask for the new password next time. One tap on Go to Review and he is back to work.

## Recap

Things to remember. The message is the same whether or not the address has an account. A reset link works once, and only for one hour. And a reset signs out every other device.
