Design system

Shelfie design system

Shelfie helps Nia log each chapter she reads, answer a few questions and collect stickers and rewards from her dad. This system writes down every visual and interaction decision the mocks already make, so each screen built from here is consistent, accessible in both themes and a little bit delightful.

How to use

In the Angular app

  1. Load tokens/tokens.css first, then assets/components.css. Do not copy values out of them.
  2. Build each sh-* component in the components library with the class names and attributes from its page here. States come from real attributes (disabled, aria-invalid, aria-pressed, aria-current, aria-busy); data-state exists only so these pages can show a state without a pointer.
  3. Theme with data-theme="light|dark" on <html>; with neither, the OS preference applies.
  4. Need a value in TypeScript or the API (e-mail templates, canvas drawing)? Read tokens/tokens.json (W3C DTCG format; dark values under $extensions).

Changing the system

Change a brand hue in the primitives, a meaning in the semantic tier, a component look in its component tokens. After any colour change run check_contrast.py; after any page change run check_design_system.py. Both live in .claude/skills/extracting-design-systems/scripts/.

python3 .claude/skills/extracting-design-systems/scripts/check_contrast.py docs/design-system/tokens/tokens.css
python3 .claude/skills/extracting-design-systems/scripts/tokens_to_json.py docs/design-system/tokens/tokens.css
