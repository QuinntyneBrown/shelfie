Foundation · Layout

Layout

A mobile-first grid of 4, 8 and 12 columns whose gutters and margins grow at 768px and 1024px, a 1280px container and six page templates.

Overview

Shelfie is mobile first. Base styles target a 360px phone; two breakpoints (768px and 1024px) add columns, wider gutters and wider margins by changing three tokens, so components rarely need their own media queries. Content is centred in a 1280px container.

  • Lay pages out on .container + .grid; the grid reads --layout-columns, --layout-gutter and --layout-margin.
  • Use min-width queries in rem only (drift D5 removed the max-width: 63.99rem overrides).
  • No page scrolls sideways at 320px.

  • .grid is repeat(var(--layout-columns), minmax(0, 1fr)) with gap: var(--layout-gutter).
  • .span-4, .span-5, .span-7, .span-8 are full width until 1024px, then take that many of 12 columns. Use 8 + 4 for a main column with an aside (Review; Add a book with its cover preview), 7 + 5 for her answers beside the feedback form (Review a chapter).
  • .grid--auto fills cards at a minimum of 18rem each (book cards on the shelf).

Container and measure

  • .container is full width, capped at --layout-container-max (1280px), centred, with --layout-margin on both sides.
  • Prose stops at --layout-measure (65ch); every <p> has it as a max-width.
  • The auth card is 26rem wide and centred in the viewport (.auth-layout, .auth-card); a dialog panel is 32rem.

Top bar and tab bar

Reader top bar: brand, streak, avatar. No navigation; her shelf is the only place to be.
Review 2 Books Settings
Grown-up tab bar on phones (64px, --layout-tabbar-height); from 768px the same three links move into the top bar.
  • The top bar is 56px (--layout-topbar-height), sticky, and the page sets scroll-padding-top to its height plus 16px so focused and linked content is never hidden under it.
  • The tab bar is fixed to the bottom on phones, adds env(safe-area-inset-bottom), and the page wrapper .has-tabbar pads the bottom so nothing sits under it.
  • --layout-sidebar-width (256px) is used by this documentation site's navigation only; Shelfie itself has no sidebar.

Usage

  • Put spans on grid children with the .span-* classes; never write style="grid-column: span 8" plus a max-width override (drift D5 fixed 16 mocks that did).
  • A page has one .container; full-bleed elements (top bar, banners) sit outside it.
  • Use 100dvh, not 100vh, for full-height layouts so mobile browser bars do not clip content.
  • Never hide content at a breakpoint that is not reachable another way; the tab bar and top-bar nav carry the same three links.

Accessibility

  • Reflow (1.4.10): every page works at 320px CSS width with no sideways scroll; only data tables scroll, inside .table-wrap.
  • Focus not obscured (2.4.11): the sticky top bar, fixed tab bar and toasts never cover the focused element.
  • Order (2.4.3): visual order equals DOM order at every width; asides come after the main column in the source.
  • Landmarks: one header, nav (labelled "Primary" or "Primary, phone"), main per page.
