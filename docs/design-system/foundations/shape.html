Shape

Soft corners scaled to the object, two border widths, and the fixed sizes for avatars and book covers.

Overview

Shelfie is soft: 12px corners on fields and covers, 24px on cards, the hero and dialogs, 32px on sheets and streak rewards, and full pills for buttons, badges, chips, avatars and stickers. Rounder means friendlier for a young reader, and one radius per size keeps it from looking random. This page also holds the fixed sizes for avatars and book covers.

RadiusUse it for
--radius-xsConfetti pieces, documentation swatches
--radius-smSmall covers, menu items, skeleton lines, close buttons
--radius-mdText fields, menus, alerts, toasts, every cover from md up (book card, hero, celebration), her answer wells, sticker choices
--radius-lgCards, hero, tables, dialogs from 640px, feedback note, trophy, achievement badges, chat bubbles, logo tile
--radius-xlTop corners of a bottom sheet (dialogs under 640px), streak-reward cards, marketing feature cards
--radius-fullButtons (pills), the floating top bar, badges, chips, streak, avatars, stickers, swatches and progress bars

Rule of thumb: the bigger the object, the bigger the radius, and a child's radius is never larger than its parent's. A 44px field gets 12px; a button or a 24px badge is a pill; a card gets 24px so the 12px cover inside it never looks rounder than its parent.

Border widths

--border-width-hairline
--border-width-thick
  • Hairline (1px) for every edge: cards, fields, dividers, list rows, buttons.
  • Thick (2px) for edges that carry state: the selected cover swatch, the button spinner, the toast timer, the hover ring on an avatar button and a hovered link's underline.
  • The focus ring has its own width, documented in Accessibility.

Avatar and cover sizes

N N MB
Avatar sm 32px (top bar), md 40px (lists, dialog icons, stickers), lg 56px (settings), xl 64px (empty-state icons).
🦁 🦁 🦁 📚
Cover sm 44px (lists, tables; radius sm), md 80px (book cards), lg 120px (hero, book page), xl 160px (finished-book celebration). md and up all use radius md, like a real book. Covers are 2:3 and the sticker is 40% of the width (drift D13).

Usage

  • Use the radius token for the component's size; never mix radii inside one component (the bottom sheet is the one exception: rounded top, square bottom against the screen edge).
  • Never type border-radius: 50% or 9999px; use --radius-full.
  • Never set 1px or 2px borders by hand (drift D12); use the border-width tokens.
  • Avatars and covers come in the four sizes above only (drift D13 removed the raw sizes).
