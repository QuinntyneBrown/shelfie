Typography

One rounded system face, a nine-step scale in rem and twelve role shorthands, tuned so a 9-year-old can read her own answers comfortably.

Overview

Shelfie uses the system's rounded face (SF Pro Rounded on Apple devices, Nunito or the platform UI font elsewhere): friendly for a 9-year-old, clear for her dad, and free to load. One family does both display and body; a monospace face is only for error codes. Sizes come from a fixed scale in rem, so the text grows with the browser's font setting.

  • Set text with a role (font: var(--text-body)), not with loose sizes and weights.
  • Body text is 16px and never smaller than 12px; her answers use the relaxed line height.
  • Headings use text-wrap: balance; paragraphs use text-wrap: pretty and stop at the measure.

The stacks start with ui-rounded, which bleeding-edge Chrome on macOS resolves to SF Pro Rounded. No web font is downloaded; if a rounded face is missing the stack falls back to the platform UI font, which keeps the same metrics closely enough that nothing reflows.

Role shorthands

Each --text-* token is a complete font shorthand: weight, size, line height and family. Components set font: var(--text-label) and override at most the size (buttons do, for sm and lg).

--text-display
Celebrations: the finished-book and chapter-done headings

You finished the whole book!

--text-h1
One per page: greeting or page name

Hi Nia 👋

--text-h2

Matilda

--text-h3
Hero title, section headings, empty-state titles, dialog titles from 640px

Nothing to review

--text-h4

Measure and responsive type

  • Measure: paragraphs stop at --layout-measure (65 characters). Empty-state and celebration text stops at 36 characters so it reads as one or two short lines for a young reader.
  • Fixed steps, no viewport units. Type does not scale with the window, so browser zoom and the user's font size always win. The one responsive change is the dialog title, which is --text-h4 on a phone sheet and --text-h3 from 640px.
  • Numbers that change in place (stats, progress labels, chapter bubbles, the count badge) use font-variant-numeric: tabular-nums so they do not jitter.
  • Long titles wrap; they truncate with an ellipsis and a title only in one-line rows such as the trophy shelf and .table td.truncate.

Usage

  • One <h1> per page and headings in order; pick the role for its look, the element for its level (a card title is an <h2> with .card__title, drift D8).
  • Uppercase only through --text-overline with --letter-spacing-wide; never type copy in capitals.
  • Do not set font sizes in px or add steps between the scale's steps. If a size is missing, the design is asking for a new role; raise it.
  • Emoji sit inline with text at the text's size ("Hi Nia 👋"); they are decoration, so the words must make sense without them.

Accessibility

  • Resize text (1.4.4): all sizes are rem; pages work at 200% zoom with no loss.
  • Text spacing (1.4.12): nothing clips when line height is 1.5×, paragraph spacing 2×, letter spacing 0.12em and word spacing 0.16em; containers grow instead of fixing heights.
  • Contrast: body and label text use default or muted colour (4.5:1 or more); large text (24px, or 18.7px bold) may use 3:1 but none currently needs to.
  • Minimum size: 12px for captions and badges only, never for something she has to act on.
