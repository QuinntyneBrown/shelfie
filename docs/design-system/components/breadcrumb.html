Breadcrumb

A short trail above the page title that says where you are and takes you back up: "My shelf / The Wild Robot", "Review / Chapter 11".

WCAG 2.2 AAStatus: stableNative <nav> + <ol>

Overview

Use a breadcrumb at the top of main on every page that sits under another: a book, add a book, log a chapter, a chapter, review a chapter, manage a book. Shelfie is at most three levels deep, so a trail has two or three items: the ancestors (links) and this page (plain text). Chapter pages go through their book: My shelf / The Lion, the Witch and the Wardrobe / Chapter 9. Top-level pages (shelf, Review, Books, Settings) have no breadcrumb.

A breadcrumb is not the main way around; the top bar and tab bar are. It is the quick "back" that survives a page reload.

Anatomy

  1. Parent linkAn <a> in --color-fg-muted, no underline until hover.
  2. SeparatorA "/" drawn by CSS (li + li::before) in --color-fg-subtle; not read aloud.
  3. Current pagePlain text in --color-fg-default, medium weight, with aria-current="page".

Variants

One component; the root changes with who is signed in.

HTML
<nav aria-label="Breadcrumb">
  <ol class="breadcrumb">
    <li><a href="/shelf">My shelf</a></li>
    <li aria-current="page">Add a book</li>
  </ol>
</nav>

Sizes

One size, --text-body-sm with --space-2 between items.

States

The parent link has default, hover and focus states, forced here with data-state. The current page is not interactive.

  • Hover darkens the link to --color-fg-default and underlines it, so it reads as a link even though it rests without an underline.
  • Loading pages still show the full breadcrumb; the trail is known before the data arrives.

Responsive behaviour

  • The list wraps (flex-wrap). A long current title ("Chapter 11 · The Lion, the Witch and the Wardrobe") drops to a second line at 360px instead of truncating, so the full name is always visible.
  • No collapsing or "…" items: trails are never longer than three, and a three-item trail wraps cleanly at 360px.

  2. Chapter 11 · The Lion, the Witch and the Wardrobe
At 360px the current page wraps under the parent.

Theming

Three text tokens and nothing else: --color-fg-muted for links, --color-fg-default for hover and the current page, --color-fg-subtle for separators. Each is defined for both themes, so the trail sits on --color-bg-canvas in either.

Accessibility

Role and pattern

The WAI-ARIA APG Breadcrumb pattern: <nav aria-label="Breadcrumb"> containing an ordered list; the last item has aria-current="page". Separators are CSS generated content, so they are not announced.

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links in order. The current page is text, not a tab stop.
EnterFollows the parent link.

Focus

The shared 2px --color-focus-ring with 2px offset around the link.

Labelling

The landmark is labelled "Breadcrumb" so it is distinct from the "Primary" nav. Link text is the parent page's name exactly as its own heading says it.

Contrast

Link on canvas
Current page on canvas
Separator on canvas
Focus ring on canvas

Motion

None.

Touch

The link is inline text in --text-body-sm, so its hit area is close to the 24px minimum only by line height. It is a secondary route: the brand in the top bar and the tab bar are the 44px targets for the same destinations.

Content

  • Each ancestor is named as its page heading: "My shelf", "Review", "Books", or the book title.
  • The current item repeats this page's subject. On Review a chapter it adds the book so Dad knows which one: "Chapter 11 · The Lion, the Witch and the Wardrobe".
  • Never "Home" or "Back".

Code

<main id="main" class="container">
  <nav aria-label="Breadcrumb">
    <ol class="breadcrumb">
      <li><a href="/review">Review</a></li>
      <li aria-current="page">Chapter 11 · The Lion, the Witch and the Wardrobe</li>
    </ol>
  </nav>
  <div class="page-header"> … </div>
</main>
Class / attributeEffect
.breadcrumbOn the <ol>: wrapping row, small muted text, "/" separators.
aria-current="page"On the last <li>: default colour, medium weight.
data-state="hover|focus"Documentation only: forces a link state.
