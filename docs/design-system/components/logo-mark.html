Logo mark

The Shelfie app icon as its own tile: a violet rounded square with three books on a shelf. It sits centred above the card on every sign-in style screen.

WCAG 2.2 AAStatus: stable<span> with <img>

Overview

Use the logo mark only on the auth pages: sign in, sign up, accept invite, forgot password and reset password. It goes above the card, once per page, and it is decoration, so it is hidden from assistive technology.

The top bar does not use it. The top bar shows a plain brand link with a small icon, described on the top bar page. Do not use the mark as an avatar or a sticker.

Anatomy

  1. TileA grid box that centres the image, sized by --size-avatar-xl, with --radius-lg corners and clipped overflow.
  2. ImageThe app icon bitmap, logo.png, 64 by 64px, scaled to fill the tile without cropping.
  3. Shadow--shadow-2 lifts the tile off the page so it reads as an icon, not a flat picture.

Variants

Not applicable: there is one logo mark. The only optional addition is the slow sway, sticker--bob, which the auth mocks apply.

Still, then swaying with sticker--bob. The auth mocks use the swaying form.
HTML
<span class="logo-mark"><img src="logo.png" alt="" width="64" height="64"></span>
<span class="logo-mark sticker--bob"><img src="logo.png" alt="" width="64" height="64"></span>

Sizes

The tile is fixed at 64px, which is --size-avatar-xl. It has no small or large form.

64px square, --radius-lg corners.

The source frame is also 64px, so the icon is crisp on a 1x screen and slightly soft on high-density screens. A 128px source image is the follow-up that fixes this; the tile size stays the same.

States

Not applicable: the logo mark is decorative and cannot be focused, hovered, disabled or loading. Its only motion is the optional sway described under accessibility.

Responsive behaviour

  • The tile stays 64px at every viewport width. It does not scale with the screen.
  • On auth pages it is centred in the card column by .auth-card .logo, so it stays centred from phone to desktop.

Theming

The tile is a bitmap, so the artwork is identical in light and dark. Only the shadow changes, because --shadow-2 is redefined per theme.

Accessibility

Role and pattern

Decorative. The image has alt="" and the wrapper has aria-hidden="true", so a screen reader skips it. The page <h1> names the screen, for example "Welcome back".

Keyboard and focus

Not interactive, so it is never in the tab order.

Contrast

The tile is non-text decoration and carries no information, so no contrast ratio applies.

Motion

The optional sway is one slow loop (--duration-loop) and purely decorative. The motion tokens set it to zero under prefers-reduced-motion, so the tile then stays still.

Content

  • Never put text inside the tile or draw a caption over it.
  • Never replace the image with an emoji. Emoji glyphs are not symmetric, so they sit off-centre in a shape.
  • Always use alt="". A real alt would make a screen reader announce the logo above every heading.
