Radio group

Pick one from a short list: how Shelfie looks, or where a new question goes. Native radios in a fieldset, each with a full-width label.

Overview

A radio group is a <fieldset> with a <legend> and two to four <label class="choice"> rows. Each row wraps its <input type="radio"> and a .choice__text, which can carry a one-line description in <small>.

Twelve mocks use radios. Two kinds:

  • Text choices, documented here: Appearance in Settings (4 mocks) and "Where it goes" in the Add a question dialog (4 mocks).
  • Visual choices: cover colour and sticker on Add a book (4 mocks), and the reader's colour in Settings. They are radios too, styled as swatches and a sticker grid.

Use a radio group when the options are few, known and mutually exclusive, and seeing them all helps the choice. Use chips for quick picks that fill a field (reward ideas), and a menu for actions, never for values.

Anatomy

  1. LegendNames the group; --text-label, or --text-h4 when the fieldset is a card.
  2. Radio24px circle, appearance: none, hairline --color-border-strong; filled --color-accent with an 8px dot when checked.
  3. Label text.choice__text; the whole row is the click target.
  4. Description (optional)<small> in --color-fg-muted.

Variants

The same rows sit either on their own in a dialog, or in a fieldset that is itself a card on a settings page.

Appearance

Applies on every device for both of you.

As a card (Settings): fieldset.card, the legend sits at the top of the card, help joined with aria-describedby on the fieldset.
HTML
<fieldset class="card stack" aria-describedby="theme-help">
  <legend style="font: var(--text-h4); margin-bottom: var(--space-2);">Appearance</legend>
  <p class="field__help" id="theme-help">Applies on every device for both of you.</p>
  <label class="choice"><input type="radio" name="theme" value="system" checked>
    <span class="choice__text">Match the device<small>Light in the day, dark at night if the device does that</small></span></label>
  <label class="choice"><input type="radio" name="theme" value="light"><span class="choice__text">Always light</span></label>
  <label class="choice"><input type="radio" name="theme" value="dark"><span class="choice__text">Always dark</span></label>
</fieldset>
Where it goes
Plain (Add a question dialog): a bare fieldset with a label-sized legend.

Sizes

One size: a 24px radio in a row at least --target-min tall.

States

Hover and focus are forced on the input with data-state; checked and disabled use the real attributes.

Both themes

Appearance
Appearance
  • Disabled is the submitting state: every radio in the form is disabled while Settings or the Add a question dialog saves, and the label text turns --color-fg-disabled.
  • Invalid never happens in Shelfie: every group starts with a sensible choice already checked. .choice input[aria-invalid="true"] exists but is not used.

Responsive behaviour

  • Rows always stack, one option per line, at every width; they never sit side by side.
  • Label and description wrap under the text start, not under the radio, because the row is a flex container with the radio aligned to the top.
  • In a dialog that becomes a bottom sheet under 640px, the group keeps its layout.

Theming

The radio reads --color-bg-surface and --color-border-strong unchecked, --color-fg-muted for the hover border, --color-accent and --color-fg-on-accent checked, and --color-bg-subtle with --color-border-default disabled. In dark the checked fill becomes the light violet and the dot turns dark, so the checked mark keeps its contrast.

Accessibility

Role and pattern

Native radios in a fieldset and legend, which give the WAI-ARIA APG Radio Group behaviour for free. All radios in a group share one name, and each has its own value.

Keyboard

KeyAction
Tab / Shift+TabMoves into the group, landing on the checked radio, and out again. The group is one tab stop.
↓ / →Checks the next option, wrapping to the first.
↑ / ←Checks the previous option, wrapping to the last.
SpaceChecks the focused option if it is not already checked.

Focus

The shared ring is drawn around the 24px circle on :focus-visible. Arrow keys move focus and selection together, so the ring is always on the checked option.

Labelling

The legend names the group ("Appearance", "Where it goes") and is read on entry. The label text names each option; its <small> description is part of the label. Help for the whole group goes on the fieldset with aria-describedby.

Contrast

Unchecked edge on card
Unchecked edge in a dialog
Checked fill on card

Description on card

Motion

Fill and border transition over --duration-fast; zeroed under reduced motion.

Touch

The whole row is the label, at least --target-min (24px) tall with --space-1 padding above and below, and as wide as the fieldset.

Content

  • The legend is a short noun or phrase: "Appearance", "Where it goes".
  • Options are parallel and short, in sentence case: "Always light", "Always dark". Put the recommended or default option first.
  • Add a description only when the option needs it: "First" says when you would want it: "Good for a warm-up question".
  • No trailing punctuation on options.
