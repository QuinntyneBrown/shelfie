Cover picker

Adds, changes or removes a book’s cover picture, such as a photo of the real cover. It has no preview of its own: the page’s book cover shows the picture as soon as it is chosen.

WCAG 2.2 AAStatus: new<sh-cover-picker>

Overview

Use the cover picker on Add a book, under the colour and sticker, and on Manage a book, beside the large cover in the header. The picture is optional: the colour and sticker cover stays underneath and shows whenever there is no picture or it fails to load.

On Add a book the chosen picture is kept in the browser and sent after the book is saved. On Manage a book choosing a picture uploads it at once and Remove picture takes effect at once. The photo picker is for people; this picker is for books.

Anatomy

  1. Label"Cover picture", or "Cover picture (optional)" in a form; it names the group.
  2. Add a pictureA small label.btn around a visually hidden input type="file"; "Change picture" when there is one.
  3. Remove pictureA small ghost button, shown only when there is a picture.
  4. Help and statusWhat to pick; during upload, "Uploading the picture…" in a polite live region.
  5. ErrorA .field__error linked with aria-describedby.

  • Focus lands on the hidden input; the label button draws the shared focus ring (:has(input:focus-visible)).
  • Uploading (Manage a book only) sets aria-busy on Change picture and disables both buttons.
  • Invalid (too large, wrong type) is decided in the browser before anything is sent, and again by the server. The cover keeps its old picture, or its colour and sticker.
  • Failed (network, server) is shown by the page as a danger alert with Try again, not by the picker.

Responsive behaviour

  • The two buttons sit in a row and wrap below each other in a narrow column, such as the Manage a book header on a 360px phone. Nothing scrolls sideways.

Accessibility

Role and pattern

A role="group" named by its label, holding a native file input inside a label, so the button’s text is the input’s accessible name. Help, status and error are tied to the input with aria-describedby; aria-invalid is set while an error shows.

Keyboard

KeyAction
TabAdd a picture, then Remove picture.
Enter / SpaceOpens the device’s file chooser, or removes the picture.

Announcements

"Uploading the picture…" is read from the status line and errors from the error line. After a removal focus moves to Add a picture.

The picture

The cover picture is decorative (alt="" inside the aria-hidden cover): the book’s title is always printed beside it.

Touch

Both buttons meet the 44px target through the button’s padding. On phones the file chooser offers the camera, so she can snap the real cover.

Content

  • "Add a picture" with no picture, "Change picture" with one, "Remove picture".
  • Help: "A photo of the real cover. JPEG, PNG or WebP, up to 5 MB."
  • Errors say what to do: "That picture is too big. Pick one under 5 MB." · "Shelfie can’t use that file. Pick a JPEG, PNG or WebP picture."
