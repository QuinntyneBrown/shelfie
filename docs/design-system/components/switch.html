Switch

One on or off choice with a short label, like "Keep me signed in". A track and a thumb that springs across, built on a native checkbox.

WCAG 2.2 AAStatus: stablelabel.switch + input[type=checkbox]

Overview

Use a switch for one setting that is either on or off and that is saved with the form it sits in. On the sign-in page, "Keep me signed in" is read when she presses Sign in. In Settings, the four household notification choices ("Tell Nia when I send a sticker or note") are read when Dad presses Save settings.

  • Switch (label.switch): a native checkbox followed by a short label.
  • Acts at once: one exception. "Notify this device" is the state of this browser, not of the household, so it takes effect when flipped, shows a toast and is outside the form's Save. It is disabled when the browser has blocked notifications.

For a choice between several options use a radio group. For a setting that needs its own Save button, use a form field instead.

Anatomy

  1. TrackThe checkbox itself, --size-icon-md tall and 1.75 times as wide, fully round. --color-border-strong when off, --color-accent when on.
  2. ThumbA --color-bg-surface circle with --shadow-1. It sits left when off and springs right when on.
  3. LabelA short statement in --text-body. An optional small line under it exists in the CSS but is not used.

Variants

There is one variant. It is off unless the page says otherwise.

The sign-in switch, on by default.
HTML
<label class="switch"><input type="checkbox" name="remember" value="1" checked><span class="switch__text">Keep me signed in</span></label>

Sizes

Not applicable. The switch has a single size at every width.

States

OffOnHoverFocusDisabled offDisabled on

Both themes

  • Hover darkens the off track to --color-fg-muted and the on track to --color-accent-hover.
  • Focus draws the shared focus ring around the track.
  • Disabled uses --color-border-default for the track and --color-fg-disabled for the label. The sign-in page disables the switch while it is submitting.

Responsive behaviour

  • The switch does not change size with the viewport.
  • The track never shrinks (flex: none); a long label wraps beside it.
  • The whole label row is the tap target, so it is easy to hit on a phone.

Theming

Every colour is a token, so the switch follows the theme with no overrides. The on track uses the accent, the off track uses the strong border colour, and the thumb uses the surface colour so it stays visible against both tracks in light and dark.

Accessibility

Role and pattern

This is a native checkbox styled as a switch (appearance: none). It follows the APG checkbox pattern, not the APG switch pattern. role="switch" is optional and is not used, so assistive technology says "Keep me signed in, checked" or "not checked", which matches what the visual shows.

Keyboard

KeyAction
TabMoves focus to the switch. A disabled switch is skipped.
SpaceToggles the switch.

Focus

The shared focus ring on :focus-visible, offset from the track so it never touches the thumb.

Labelling

The visible text is the accessible name because the input sits inside its label. No aria-label is needed.

Motion

The thumb springs across with --ease-spring over --duration-base, and the track colour fades with --ease-standard. Reduced motion zeroes both durations, so the thumb jumps.

Touch

The label row is at least --target-min tall, and clicking the label text toggles the switch. The target is larger than the 24px minimum.

Content

  • The label is a short statement about what happens when it is on: "Keep me signed in".
  • A switch is on by default only where the page says so. Sign-in and the four household notification choices are; nothing else is.
  • No explanatory line under the label. The mocks dropped it as too wordy.
