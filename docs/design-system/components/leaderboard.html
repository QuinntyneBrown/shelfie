Leaderboard

The readers taking part in a household challenge, ranked by their count, each with an avatar, a name and progress toward the goal. The leader wears a crown. Review shows it to Dad; Nia's shelf shows it with her own row tinted.

WCAG 2.2 AAStatus: new<sh-leaderboard>

Overview

Use a leaderboard only for a challenge with two or more readers. With one reader there is no one to race, so show a large progress bar toward the goal instead (see the leaderboard pattern). Rows come in the order the API sends: highest count first, then by name. It composes Avatar and Progress; it adds no colour of its own except the "you" tint and the lead tag.

Anatomy

  1. Rank.leaderboard__rank: the position, or 👑 for a leader. Equal counts share a rank.
  2. Avatarsh-avatar, the reader's photo or initial on her colour.
  3. Name and lead tag.leaderboard__name; .leaderboard__lead reads "In the lead".
  4. Progresssh-progress: the count out of the goal, e.g. "9 of 15". A count above the goal fills the bar.

Responsive behaviour

One column at every width. The name truncates before the progress bar shrinks below 6rem; at 360px a row is rank, avatar and a body that stacks the name over the bar.

Theming

The "you" row reads --color-accent-subtle; the lead tag --color-warning-fg on --color-warning-bg. Both have dark values in the token file.

Accessibility

An <ol> labelled "Leaderboard", so a screen reader announces the number of readers. The crown is not read; the rank cell carries aria-label ("1st, in the lead"). Each bar is a progressbar named "Nia: 9 of 15 chapters". Nothing is focusable. The "you" tint is never the only cue: the row also says "(you)".

Content

  • Names exactly as the reader's profile spells them.
  • Counts as numerals, "9 of 15"; the unit lives in the card's subtitle ("Chapters logged · goal 15").
  • Encourage, never shame: the line under the board says how many to catch up, not how far behind.

Code

<sh-leaderboard [rows]="standings" [goal]="15" unit="chapters" [you]="readerId" />

Each row is { readerId, name, color, photo, count, rank, leading }. The static markup:

<ol class="leaderboard" aria-label="Leaderboard"><li class="leaderboard__row leaderboard__row--leader"><span class="leaderboard__rank" aria-label="1st, in the lead">👑</span><span class="avatar avatar--rose" aria-hidden="true">N</span><div class="leaderboard__body"><div class="leaderboard__name">Nia <span class="leaderboard__lead">In the lead</span></div><div class="progress-row"><div class="progress" role="progressbar" aria-valuenow="9" aria-valuemin="0" aria-valuemax="15" aria-label="Nia: 9 of 15 chapters"><div class="progress__bar" style="--value: 60%;"></div></div><span class="progress-row__label">9 of 15</span></div></div></li></ol>
