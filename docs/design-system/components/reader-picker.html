Reader picker

Which reader a parent page is about, when there is more than one.

WCAG 2.2 AAStatus: newLibrary: sh-segmented
  • Overview
  • States
  • Accessibility
  • Content
  • Sources

Overview

Not a new component: the existing chip group, sh-segmented, labelled “Reader”, one chip per reader (ADR-0019). It appears on Review, Books and Add a book only when the household has two or more readers, and the choice is remembered on the device. Pages about one book name its reader with an avatar and her name instead.

States

Reader
On Review, each chip counts that reader’s waiting chapters.
HTML
<div class="field"><span class="field__label" id="rp-label">Reader</span><div class="cluster" role="group" aria-labelledby="rp-label"><button class="chip" type="button" aria-pressed="true">Nia · 2</button><button class="chip" type="button" aria-pressed="false">Theo · 1</button></div></div>

Accessibility

A group named “Reader” of toggle buttons with aria-pressed; Tab moves between chips, Space or Enter picks.

Content

Readers’ names as set in Settings, sorted by name. On Review, “Nia · 2”.
