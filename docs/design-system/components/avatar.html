Component · Identity

Avatar

A circle with initials that stands for a person. Nia is "N" in rose, Dad is "MB" in sky, everywhere: the top bar, the profile picker and the PIN screen.

WCAG 2.2 AAStatus: stable<span> or <button>

Overview

Use an avatar wherever a screen is about one of the two people in the household. There are no photos: each person has initials and a colour, set once, so a nine-year-old can tell at a glance whose screen she is on.

  • Static (span.avatar): decoration next to a name, as on the profile picker and PIN screen.
  • Button (button.avatar): the top-bar trigger for the account menu.

Avatars are not for books; books use a cover. Do not use them for status; use a badge.

Anatomy

  1. InitialsOne or two capitals in --text-label, dark --color-fg-on-cover on a person colour.
  2. Circle--radius-full, sized by --avatar-size (32, 40 or 56px), filled with the person's colour.

Variants

The colour is the person. Nia is always rose, Dad always sky. The plain avatar (accent tint) is the fallback before a colour is set.

N MB N
Rose (Nia), sky (Dad), plain fallback. All three are decorative here because a name sits next to each in use.
HTML
<span class="avatar avatar--rose" aria-hidden="true">N</span>
<span class="avatar avatar--sky" aria-hidden="true">MB</span>
<span class="avatar" aria-hidden="true">N</span>

Button avatar

The top-bar trigger. button.avatar resets the border and adds a hover ring; no inline style needed.
HTML
<button class="avatar avatar--sm avatar--sky" type="button"
        aria-label="Account menu for Dad" aria-haspopup="menu" aria-expanded="false">MB</button>

Sizes

Small sits in the 64px top bar. Medium is the default; on the sign-in profile picker the profile tile enlarges it to 64px. Large heads the PIN and password screens, where the avatar confirms who is signing in.

N N N
Small · 32px, medium · 40px, large · 56px: --size-avatar-sm/md/lg. The profile tile enlarges it to 64px (--size-avatar-xl).

A static avatar has no states. The button avatar has the states below; aria-expanded="true" is set while the account menu is open.

Both themes

NMBN
NMBN
  • Hover draws a 2px ring in --color-border-strong around the circle.
  • Focus uses the shared focus ring, outside the hover ring.
  • There is no disabled or loading avatar: the account menu is always available.

Responsive behaviour

  • Sizes do not change with the viewport. The top-bar avatar is 32px at every width.
  • The avatar never shrinks inside a flex row (flex: none), so a long book title wraps around it instead.

Theming

Person colours reuse the cover pastels: --color-cover-rose and --color-cover-sky, both with dark --color-fg-on-cover initials in either theme, so Nia's avatar looks the same in light and dark. The plain fallback uses --color-accent-subtle with --color-fg-accent and does follow the theme. A new person colour is a new .avatar--{cover} modifier that sets the same two properties.

Accessibility

Role and pattern

Static avatars are a <span aria-hidden="true"> next to the visible name. The account trigger is a native <button> following the APG menu button pattern: aria-haspopup="menu" and aria-expanded.

Keyboard

KeyAction
TabFocuses the button avatar (last item in the top bar).
Enter / Space / ↓Opens the account menu and moves focus to its first item.
EscCloses the menu and returns focus to the avatar.

Focus

The shared 2px ring with a 2px offset on :focus-visible. When the menu closes, focus comes back here.

Labelling

Initials are not a name a screen reader can use. The button carries aria-label="Account menu for Nia"; a static avatar is hidden because the name is printed beside it ("Nia · Reader").

Motion

None. The hover ring appears instantly.

Touch

The 32px top-bar button clears the 24px minimum and has 16px of space on each side in the top bar. Use medium or larger wherever the avatar is the only target on a phone.

Content

  • Initials: the first letter of the first name for the reader ("N"), first and last initials for the grown-up ("MB").
  • Never more than two letters; capitals only.
  • The button's label says what it opens and for whom: "Account menu for Dad".
