Join code

A community’s join code, easy to read out and to copy.

WCAG 2.2 AAStatus: newLibrary: sh-join-code
  • Overview
  • States
  • Accessibility
  • Content
  • Tokens
  • Code
  • Sources

Overview

The eight-character code a parent gives another parent to join a community (ADR-0020), shown large, spaced and selectable, with a Copy button. On a community page.

States

KQ7M-3HTP
Default.
HTML
<div class="join-code"><span class="join-code__value" aria-label="Join code K Q 7 M 3 H T P">KQ7M-3HTP</span><button class="btn btn--sm" type="button">Copy code</button></div>
KQ7M-3HTPCopied to the clipboard
Just copied: the button says “Copied!” for two seconds and a status line is announced.
HTML
<div class="join-code"><span class="join-code__value" aria-label="Join code K Q 7 M 3 H T P">KQ7M-3HTP</span><button class="btn btn--sm" type="button">Copied!</button><span class="inline-status inline-status--success" role="status">Copied to the clipboard</span></div>

Accessibility

The code has an aria-label that spells it character by character. Copy is a real button; its result is announced through a role="status" line. The code itself is selectable (user-select: all) for browsers that refuse the clipboard.

Content

Shown as ABCD-EFGH. Typing it back, capitals and the dash don’t matter.

Tokens

--font-family-mono, --font-size-xl, --color-bg-surface-sunken, --color-border-strong (dashed), --radius-md.

Code

Angular: <sh-join-code [code]>. Classes: .join-code, .join-code__value.
