Sticker

One emoji in a soft accent circle. Stickers are Shelfie's small delights: the 🌟 Dad gives a chapter, the 🏆 for a finished book, the 🎉 when Nia logs a chapter.

Overview

Use a sticker to mark a moment or a kind of event with a picture a child reads instantly. It is always decorative: the words next to it carry the meaning. To let Dad choose a sticker, use the sticker picker; for a book's face, use a cover; for a person, use an avatar.

The six stickers Dad can give are 🌟 Star, 🦉 Wise owl, 🚀 Rocket, 🐉 Dragon, 🍪 Cookie and 💡 Bright idea. Other stickers mark events: 📖 a chapter logged, 📚 a book added, 🏆 a book finished, 🎉 a chapter done.

Anatomy

  1. EmojiHalf the circle's width (54% at extra large), line height 1, centred.
  2. Circle--radius-full on --color-accent-subtle, sized by --sticker-size.

Variants

One look; the emoji changes. These are the stickers the mocks use.

Sizes

Size follows how big the moment is.

🏆 🏆 🏆
Medium · 40px (feed, trophy shelf) · large · 64px (Dad's feedback, the finished-book card, sign-in logo) · extra large · 96px (celebrations, error pages).

States

A sticker is not interactive: no hover, focus, active or disabled. Choosing one is the sticker picker's job, which has those states.

Responsive behaviour

  • Sizes are fixed tokens and do not scale with the viewport.
  • The sticker never shrinks in a flex row (flex: none); in feeds and feedback notes it stays top-left while text wraps beside it.
  • In celebrations it is centred above the heading at every width.

Theming

Reads only --color-accent-subtle, which deepens in dark mode so the circle stays a soft halo behind the emoji. Emoji keep their own colours in both themes.

Accessibility

Role and pattern

A <span aria-hidden="true">. Stickers are decorative; without aria-hidden, screen readers would read emoji names ("glowing star") that repeat or contradict the text.

Keyboard

KeyAction
TabSkips the sticker; it is not interactive.

Focus

Never focusable.

Labelling

The sentence beside it names the sticker when the sticker matters: "Dad gave you a Star", "You gave Chapter 9 a Star". Never rely on the emoji alone to say which sticker was given.

Contrast

Fallback glyph on circle
Fallback glyph on circle

Emoji draw in their own colours and the circle is decorative, so 1.4.11 does not apply. The pair above covers platforms that draw a monochrome fallback glyph in the text colour.

Motion

The sticker itself never moves. Celebrations add confetti around it, which is removed under prefers-reduced-motion.

Touch

Not a target.

Content

  • One emoji per sticker, from the set above. Do not invent new stickers per screen.
  • Each sticker means one thing everywhere: 📖 is always "a chapter was logged", 🏆 always "a book was finished".
  • When a sticker is given, the text uses its name with a capital: "a Star", "a Wise owl".
