Question and answer

Shows one question and the answer Nia wrote for it, exactly as she typed it. Nia reads her own answers back on the chapter page; Dad reads them on the review page.

WCAG 2.2 AAStatus: stableRead only

Overview

Use a question and answer block to play back an answer that has been sent. Answers are final once Nia taps "I'm done!", so this block never turns into a form. While she is still writing, the question is a textarea label instead.

  • Stack the blocks inside one card, in question order, under a heading: "Your answers" for Nia, "Nia's answers" for Dad.
  • Every chapter has the three default questions plus any Dad added for that book, so a card holds three to about six blocks.
  • The number (.qa__num) also numbers questions in the Manage book question list, where it sits in a list row instead of a .qa.

Anatomy

  1. Number.qa__num: "1." to "n.", accent colour, matches the order she answered in.
  2. Question.qa__q: label font, muted colour, so the answer reads as the main text.
  3. Answer.qa__a: body font, relaxed line height, line breaks kept (pre-wrap), long words broken.
  4. WellSunken surface, --radius-md, 12 × 16px padding.

Variants

There is one look. The two readers differ only in the card heading around the blocks.

Your answers

2.Who was your favourite character in this chapter, and why?
Edmund, because even though he’s being bad I felt sorry for him when he was cold and scared.
Reader view, from the chapter page (Chapter 9). Dad's view is the same with the heading "Nia's answers".

<section class="card stack" aria-labelledby="your-answers">
  <h2 id="your-answers" class="card__title">Your answers</h2>
  <div class="qa">

  </div>

Sizes

The block has one size. It takes the width of its card and grows with the answer.

States

The block is read only and never focusable, so it has no hover, focus, active or disabled state. What changes is the content and whether it has loaded.

  • Loading replaces the whole card body with a title skeleton and text skeletons; the container carries aria-busy="true". See skeleton.
  • Flagged appears only on Review a chapter, after Dad asks the review assistant for help: a warning alert ("Talk about this" plus the assistant’s reason, at most 120 characters, as plain text) sits under the answer well. The answer itself is unchanged. Nia never sees a flag, and flags are not kept.
  • Waiting for Dad is not a state of this block: the chapter page adds an alert above the card ("Dad hasn’t read this yet") and the answers look the same.

Responsive behaviour

  • The block is fluid: the answer wraps at any width and never scrolls sideways. overflow-wrap: anywhere breaks a long run of letters ("sooooo good") instead of overflowing at 360px.
  • On Review a chapter the answers card spans 7 of 12 columns from 1024px (.span-7) with the feedback form beside it; below that the card is full width and the form follows it.
  • The question wraps under its number on phones; the number does not shrink (gap: --space-2).

Theming

The block reads --color-fg-muted for the question, --color-fg-accent for the number, and --color-bg-surface-sunken with --color-fg-default for the answer well. In the dark theme the well is darker than the card, so it still reads as recessed. No component tokens are needed; a re-theme changes the semantic tokens.

Accessibility

Role and pattern

Plain structure, no ARIA role. The surrounding card is a <section> named by its heading through aria-labelledby, so "Your answers" is a landmark-like group in the rotor. The question is text, not a heading, so the heading outline stays short.

Keyboard

KeyAction
TabNot a stop. Focus moves from the breadcrumb to the next control after the card ("Back to the book").
Arrow keys (screen reader)Read number, question and answer in order, one after the other.

Focus

Nothing inside the block takes focus. Do not add tabindex to make answers focusable.

Labelling

The number is real text ("1."), so a screen reader says "1. What happened in this chapter?" and then the answer. The answer is Nia's text unchanged; never replace it with a summary.

Contrast

Question on card
Number on card
Answer in well

Motion

None. The loading skeleton shimmers and stops under prefers-reduced-motion.

Touch

No targets inside the block. Text stays selectable so Dad can copy an answer.

Content

  • Questions are full sentences ending in a question mark, in words a 9-year-old reads alone: "What do you think will happen next?"
  • The three default questions come first, in this order; questions Dad added for the book follow, numbered on ("4. Where did the children go in this chapter?").
  • Show the answer exactly as written: her spelling, her line breaks, her emoji. Do not trim, correct or quote it.
  • Heading: "Your answers" when Nia reads, "Nia’s answers" when Dad reads.
