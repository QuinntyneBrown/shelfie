Cover gallery

A grid of book covers to choose one from. It sits in a dialog opened by “More covers” on Add a book, after a catalogue match was picked.

Overview

Use it to choose one picture from several. Choosing only selects a tile; the owner applies it when “Use this cover” is pressed, so cancelling leaves the book as it was. For adding your own photo use the cover picker.

Anatomy

  1. A role="radiogroup" named “Covers”.
  2. Tiles: a native radio, visually hidden, labelled “Cover n of total”, plus an sh-cover md showing the picture or its colour-and-sticker placeholder.
  3. Selected tile: a 2 px primary outline; keyboard focus: the focus ring.

Variants

One variant: a radio grid of medium covers inside the “Pick a cover” dialog. It is not used anywhere else.

Sizes

One size: every tile shows a medium cover (--size-cover-md, 80px wide) with --space-2 padding, --space-3 apart. The column count changes with the width (see Responsive), the tile size does not.

States

  • Loading: six skeleton covers, aria-busy="true", “Getting covers…” announced politely.
  • Default: the tiles; the one matching the current picture is checked.
  • Empty: an empty state “No other covers for this book.”
  • Failed: a danger alert “Shelfie couldn’t get the covers. You can still add the book.” with Try again.
  • Picture failed to load: that tile shows the placeholder and stays selectable.

Responsive behaviour

2 columns under 40rem, 3 from 40rem, 4 from 64rem. Each tile is at least 44 px wide and tall; nothing scrolls sideways.

Theming

The gallery adds no colours of its own beyond the selection edge. Covers read the cover palette, which stays the same in both themes; the selected tile's 2px edge reads --color-accent and keyboard focus the shared --color-focus-ring, both of which flip with the theme. The dialog around it supplies the surface.

Accessibility

  • Native radios: arrow keys move and select, Space or Enter confirms; one tab stop for the group.
  • Each radio is labelled “Cover n of total”; the picture itself is decorative (alt="").
  • Selected state is shown by outline and by the radio’s checked state, not by colour alone.

Content

Dialog title “Pick a cover”. Buttons “Use this cover” and “Cancel”; “Close” and “Try again” in the empty and failed states.
