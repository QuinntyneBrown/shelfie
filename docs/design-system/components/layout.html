Layout primitives

A small set of classes that place everything else: the page container, vertical stacks, wrapping rows, the 4/8/12-column grid and its spans, the sticky aside, the page header and the centred auth card.

WCAG 2.2 AAStatus: stableCSS only, no ARIA

Overview

Compose pages from these primitives instead of writing layout CSS or inline grid-column styles. They read the layout tokens (--layout-columns, --layout-gutter, --layout-margin), which change at 768px and 1024px, so pages respond without their own media queries.

  • .container: the page width (max 1280px) and side margins. main on every signed-in page.
  • .stack: children in a column, 16px apart. Cards, forms, dialog bodies.
  • .cluster: children in a wrapping row, 12px apart, vertically centred. Button rows, sticker choices, stats. .cluster--between pushes the ends apart.
  • .grid: the column grid. .grid--auto fills with 18rem-minimum cards instead (book cards on the shelf).
  • .span-4/5/7/8/full: column spans, full width until 1024px. .sticky-aside: sticks below the top bar from 1024px.
  • .page-header (title, subtitle, action) and .section (vertical rhythm between page sections).
  • .auth-layout + .auth-card: the centred card on sign in, sign up, accept invite, forgot and reset password. The logo mark sits above the card and the background is the aurora (auth effects).

Anatomy

Review a chapter, the page that uses the most primitives at once.

  1. Containermain.container: max --layout-container-max, side padding --layout-margin.
  2. Page header.page-header: title block on the left, action on the right, wraps on phones.
  3. Grid.grid: --layout-columns equal columns, --layout-gutter apart.
  4. Main column.span-7 (or .span-8): full width until 1024px.
  5. Aside.span-5 .sticky-aside (or .span-4): beside the main column from 1024px, sticky below the top bar.

The anatomy figure forces 12 columns so it reads at any window width; real pages let the tokens choose.

Sizes

Primitives have no size modifiers; gaps and widths come from the spacing and layout tokens listed below.

States

Layout primitives are not interactive and have no states; the only change is responsive (see below).

Responsive behaviour

WidthColumnsGutterMarginSpans
Base (phones)4--space-4 (16px)--space-4 (16px)All spans full width; aside under main.
768px (--layout-breakpoint-md)8--space-6 (24px)--space-8 (32px)Still full width.
1024px (--layout-breakpoint-lg)12--space-8 (32px)--space-12 (48px).span-4/5/7/8 take their columns; .sticky-aside sticks.
  • Mobile first: base styles target 360px and only min-width queries add space. There is no desktop-first patch to undo.
  • .sticky-aside sticks at --layout-topbar-height + --space-4, so it clears the top bar.
  • .page-header wraps: on phones the action drops under the title. .cluster wraps its children; nothing scrolls sideways at 320px.

Theming

Primitives draw no colour; layout tokens change by breakpoint, not by theme.

Accessibility

Role and pattern

No roles of their own. Put them on the right native element: .container on <main id="main">, .sticky-aside on <aside> or a <section aria-labelledby>, .auth-layout on <main>.

Keyboard

KeyAction
Tab / Shift+TabFollows DOM order. Primitives add no tab stops; never reorder columns visually with order or grid-row, so focus order matches reading order (main before aside).

Focus

html has scroll-padding-top equal to the top bar plus --space-4, and .has-tabbar reserves the tab bar, so focused content is never hidden under sticky bars.

Labelling

The page header holds the page's only <h1>. Sections and asides are named by their visible heading through aria-labelledby.

Contrast

Primitives draw no colour. Text in .page-header .subtitle uses --color-fg-muted:

Subtitle on canvas
Page title on canvas

Motion

None. html uses smooth scrolling for in-page links, turned off under prefers-reduced-motion.

Touch

.cluster puts 12px between neighbours, above the spacing needed for 24px targets. Content reflows at 320px CSS width (WCAG 1.4.10).

Content

  • Page header: the title says where you are ("Review", "Hi Nia 👋"); the subtitle says what is waiting ("2 chapters to read · 1 reward to give").
  • One action in the page header at most; it is the page's main action.
