Activity feed

A short, newest-first log of what happened in the household this week. It sits in the "This week" card on Dad's Review page so he can see the rhythm of Nia's reading at a glance.

Overview

Use the feed for events: something someone did, at a time. Each entry is a sentence, not a thing with actions. If the reader needs to act on each row (review it, manage it), use a list with a button instead. The feed is read-only and has no links of its own; the actions live in the list above it.

It pairs with stats in the same card: numbers first ("Chapters 5", "Streak 🔥 5"), then the events behind them.

Anatomy

  1. StickerA 40px sticker that says what kind of event it was: 📖 logged, 📚 added, 🌟 sticker given, 🏆 finished. Decorative.
  2. Event sentence.feed__body: who did what, in body text. Wraps freely.
  3. Time.feed__meta: --text-caption in muted ink, under the sentence.

Variants

One variant. The sticker changes with the kind of event; that is the only thing that varies.

Sizes

One size. Each entry has 12px above and below and a hairline divider; the sticker is the default 40px.

States

Entries are not interactive, so there is no hover, focus, active or disabled state. The feed's states are about how much there is to show.

Responsive behaviour

  • On wide screens the feed sits in the right-hand column (.span-4) next to the review queue; below 1024px that column drops under the queue at full width.
  • Sentences wrap; nothing truncates. .feed__body has min-width: 0 so a long book title wraps instead of overflowing.
  • The sticker aligns to the top of the entry so a two-line sentence reads cleanly.

Theming

Reads --color-fg-default (sentence), --color-fg-muted (time) and --color-border-default (dividers); stickers read --color-accent-subtle. No background of its own: it inherits the card surface in both themes.

Accessibility

Role and pattern

A native <ul>. Not the APG feed pattern (role="feed"), which is for infinitely loading articles; this is a short static list.

Keyboard

KeyAction
TabSkips the feed; it has nothing to focus.
Screen reader list keysMove entry by entry; each is announced as one sentence followed by its time.

Focus

Nothing in the feed takes focus. Do not add tabindex to entries.

Labelling

The feed sits under the card heading ("This week"), which the surrounding <section> or <aside> references with aria-labelledby. The sentence carries the meaning, so the sticker is aria-hidden.

Motion

None. New entries appear on the next page load, not with an animation.

Touch

Nothing to tap. The feed is never the only route to anything; every event in it has a row in the list above or on the Books page.

Content

  • One sentence per event, subject first, past tense: "Nia logged Chapter 10", "Nia finished Matilda".
  • The grown-up is "You" ("You added Because of Winn-Dixie"); the reader is her name.
  • Name the book on the first entry about it; later entries for the same book can drop it.
  • Times: "Today, 4:12 pm", "Yesterday, 7:05 pm", then "Thu 15 Oct".
  • Use the sticker that matches the event, every time: 📖 logged, 📚 added, 🌟 or the sticker given, 🏆 finished.

Class / attributeEffect

.feed__bodyThe event sentence; flexible, wraps.
