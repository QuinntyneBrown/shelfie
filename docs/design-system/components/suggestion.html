Suggestion

One suggested question in the Suggested questions dialog: a tick to keep it and its wording, editable in place. Nothing is kept until Dad ticks it and adds it.

Overview

Angular: <sh-suggestion [number] [error] [disabled] [(chosen)] [(text)]>. A .suggestion row inside a .suggestions list (in Angular the sh-suggestion host carries role="listitem" inside a div.suggestions[role="list"]; in static HTML use ul and li), holding a native checkbox and a textarea in a form field. Use it only where Dad reviews text Shelfie wrote for him before it is saved; it is the one place AI-written words appear.

Anatomy

  1. Keep tick.suggestion__check, a native checkbox coloured with accent-color: --color-accent. Named “Keep suggestion N”.
  2. WordingA two-row .textarea, labelled “Suggestion N” for screen readers only.
  3. RowA bordered tile; ticked rows take --color-accent border and --color-accent-subtle fill.

Variants

One variant. Rows stack in a .suggestions list with --space-3 between them.

Sizes

One size: full width of the dialog body.

States

Not ticked (how every idea arrives)

Ticked

Invalid (reworded to under 5 characters)

  • Finish the question — at least a few words, ending in a question mark helps.

Disabled (while adding)

  • Focus on the tick draws the shared focus ring; focus in the wording uses the textarea's ring.
  • Invalid uses the same message and 5 to 200 character rule as Add a question (L2-013), checked only for ticked rows.
  • Disabled locks every row while the dialog adds the ticked ones.

Responsive behaviour

  • The tick stays at the top left; the wording fills the rest and wraps. In the bottom sheet under 640px the rows are full width. Nothing scrolls sideways.

Theming

Only role tokens are used.

Accessibility

Role and pattern

A list of native checkboxes and textareas. Each tick is named “Keep suggestion N” and each box “Suggestion N”, so the two are told apart. Errors are tied to the box with aria-describedby and aria-invalid. The wording is shown as plain text, never as HTML.

Keyboard

KeyAction
TabThe tick, then the wording, then the next row.
SpaceTicks or unticks.

The tick is at least --size-icon-md square and sits in a row taller than --target-min.

Content

  • Each suggestion is one question for a 9-year-old, ending in a question mark, 5 to 200 characters.
  • The dialog intro says nothing reaches Nia until Dad adds it.

Do and don't

  • Do start every row unticked, so a person reads each idea before it can be kept.
  • Don't save on tick; saving is the dialog's “Add N questions”.

  <li class="suggestion">

    <div class="field"><label class="visually-hidden" for="s1">Suggestion 1</label><textarea class="textarea" id="s1" rows="2">What clue shows that winter in Narnia is ending?</textarea></div>
  </li>
</ul>
