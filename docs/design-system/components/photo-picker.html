Photo picker

Lets a person choose, replace or remove their own profile photo. An extra-large avatar previews the result; picking a photo uploads it at once.

Overview

Use the photo picker only in the "Your photo" dialog, where a parent or a reader manages their own photo. There is no Save: choosing a file uploads it, and Remove photo takes effect at once. The person's initial comes back as soon as the photo is removed.

It is not a general file field and never edits someone else's photo. There is no cropping or filtering: the server centres and crops the photo to a square.

Anatomy

  1. PreviewAn extra-large (64px) avatar, role="img", labelled "Your photo" or "No photo yet".
  2. Choose buttonA primary label.btn around a visually hidden input type="file"; the native input keeps keyboard and assistive-technology support.
  3. Remove photoA ghost button, shown only when there is a photo.
  4. Help and statusThe allowed types and size; during upload, "Uploading your photo…" in a polite live region.
  5. ErrorA .field__error linked with aria-describedby.

  • Focus lands on the hidden input; the label button draws the shared focus ring (:has(input:focus-visible)).
  • Uploading sets aria-busy on the preview and the Choose button and disables both buttons. The dialog's Done waits too.
  • Invalid (too large, wrong type) is decided in the browser before sending and again by the server. The previous photo or initial stays.
  • Failed (network, server) is shown by the dialog as a danger alert with Try again, not by the picker.

Responsive behaviour

  • The preview and the body sit side by side and wrap; the buttons wrap below each other on narrow bottom sheets. Nothing scrolls sideways at 360px.

Only role tokens are used; the person's colour comes from the avatar.

Accessibility

Role and pattern

A native file input inside a label, so the button's text is the input's accessible name. The preview is role="img" with a label. Help, status and error are tied to the input with aria-describedby; aria-invalid is set while an error shows.

Keyboard

KeyAction
TabChoose a photo, then Remove photo.
Enter / SpaceOpens the device's file chooser, or removes the photo.

Announcements

"Uploading your photo…" is read from the status line; the dialog announces success. After a removal focus stays on Choose a photo.

Touch

Both buttons are at least 44px tall. On phones the file chooser offers the camera and the photo library.

Content

  • "Choose a photo" with no photo, "Choose another" with one, "Remove photo".
  • Help: "A JPEG, PNG or WebP photo, up to 5 MB."
  • Errors say what to do: "That photo is too big. Pick one under 5 MB." · "Shelfie can’t use that file. Pick a JPEG, PNG or WebP photo."
