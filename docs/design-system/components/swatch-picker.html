Swatch picker

A row of colour dots or a grid of stickers where exactly one is picked. Nia uses it to make a cover for a new book; Dad uses it to pick her colour in Settings.

WCAG 2.2 AAStatus: stableNative <input type="radio">

Overview

Use a swatch picker when the choice is visual and small: one colour out of seven, one sticker out of a dozen. Each option is a real radio button, so the group behaves like any other radio group. Use a radio group when the options are words, and the sticker picker when Dad picks a reward sticker for a chapter.

  • Colour swatches (.swatches) pick a cover colour on Add a book and the reader's colour in Settings. The colour comes from the --cover custom property on each .swatch.
  • Sticker grid (.emoji-grid) picks the sticker that sits on the cover. Same .swatch labels, laid out as square tiles.

Anatomy

  1. Group.swatches (or .emoji-grid) with role="radiogroup", named by the field label through aria-labelledby.
  2. Swatchlabel.swatch, a 44px round target. It sets --cover to one of the seven --color-cover-* tokens.
  3. Checked markA ✓ drawn in --color-fg-on-cover, plus a --color-fg-default ring inside a surface-coloured gap.
  4. Hidden name.visually-hidden text ("Sun") so the colour has a name, not just a hue.

Sizes

One size each. A colour swatch is a 44px circle (--target-comfortable) with 8px between dots (--space-2). A sticker tile is square, at least 48px (--space-12) and grows to share the row; the emoji is --font-size-2xl.

Swatch: --target-comfortable (44px). Tile: min --space-12 (48px).

States

Pointer and focus states are forced with data-state on the input; real pages get them from :hover, :focus-visible, :checked and :disabled.

Colour
Sticker

Both themes

  • Checked draws a ✓ and a dark ring with a surface-coloured gap, so the pick is shown by shape as well as colour. In the sticker grid the tile tints to --color-accent-subtle with an accent border.
  • Disabled is used while the form is saving (Add a book, submitting): every input gets disabled and the pick stays visible.
  • Invalid does not apply: both pickers always have a default pick (the mocks pre-check sun and the dog for Because of Winn-Dixie, rose for Nia), so the group can never be empty.

Responsive behaviour

  • Colour swatches wrap onto a second row when the field is narrower than seven dots (about 360px with gaps); they never shrink below 44px.
  • The sticker grid uses repeat(auto-fill, minmax(--space-12, 1fr)): four or five tiles a row on a 360px phone, twelve on a desktop card. Tiles stay square (aspect-ratio: 1).
  • On Add a book the picker sits in the form column; the cover preview moves below it until 1024px, then sits beside it in a .span-4 column (see layout primitives).

Theming

Each swatch reads one component token, --cover, set to a semantic --color-cover-* token. The cover palette is shared with book covers and avatars, so the colour Nia picks is the colour she sees on her shelf. In the dark theme the cover colours deepen and --color-fg-on-cover stays dark-on-pastel or flips with them, keeping the ✓ above 4.5:1.

/* A new cover colour is one token plus one swatch; the component CSS does not change. */
<label class="swatch" style="--cover: var(--color-cover-peach);">…</label>

Accessibility

Role and pattern

Native radio buttons inside an element with role="radiogroup", following the WAI-ARIA APG Radio Group pattern. The browser supplies the roving focus and arrow-key behaviour because every option shares one name.

Keyboard

KeyAction
Tab / Shift+TabMoves focus into the group (to the checked option) and out of it. The group is one tab stop.
→ ↓ / ← ↑Moves to and checks the next or previous option, wrapping at the ends. The cover preview updates.
SpaceChecks the focused option if it is not already checked.

Focus

The shared ring (--focus-ring-width --color-focus-ring, --focus-ring-offset) draws around the circle or tile on :focus-visible. It sits outside the checked ring, so focus and checked never look the same.

Labelling

The group is named by the visible field label ("Colour", "Sticker") through aria-labelledby. Each option has a .visually-hidden name: the colour word ("Sage") or the sticker word ("Dog"). The emoji itself is aria-hidden="true" so screen readers do not read "dog face" in one place and "Dog" in another.

Contrast

Check mark on sun cover
Check mark on sage cover
Sticker tile border on surface
Checked tile border on its tint
Focus ring on surface

Pastel cover fills are decorative and are not required to reach 3:1 against the card; the checked ring (--color-fg-default) and the ✓ carry the state.

Motion

Only the border colour transitions, over --duration-fast. Reduced motion zeroes the duration in the tokens.

Touch

Swatches are 44×44px with 8px gaps; sticker tiles are at least 48×48px. Both clear the 24px minimum and the 44px comfortable target. The whole label is the hit area.

Content

  • The field label is one plain noun: "Colour", "Sticker". The fieldset legend above them says what they make: "Make a cover".
  • Hidden names are one everyday word a 9-year-old would use: "Sun", "Lilac", "Dog", "Dragon". No codes, no hex values.
  • Keep the sticker set to about a dozen so the grid fits two rows on a phone.
  • Optional help sits under the label as .field__help and describes the radiogroup (aria-describedby). The reader colour uses it when the reader has a photo: "Shows when Nia has no photo." (dialogs/edit-reader/photo).
